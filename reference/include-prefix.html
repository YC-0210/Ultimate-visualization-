include chops the prefix

Source: Including other URLconfs.

Django’s docs: “Whenever Django encounters include(), it chops off whatever part of the URL matched up to that point and sends the remaining string to the included URLconf for further processing.”

DEBUG

Django: “Never deploy a site into production with DEBUG turned on.” Traces carry Cookie. If DEBUG is False, do not add the prefix. Do not flip DEBUG to test while ALLOWED_HOSTS is empty.
