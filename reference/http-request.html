HttpRequest pocket card

One Python object for one visit. Source: HttpRequest.

Django’s docs: “When a page is requested, Django creates an HttpRequest object that contains metadata about the request. Then Django loads the appropriate view, passing the HttpRequest as the first argument.”

Already there when your middleware starts

PocketWhat it is
method Uppercase string: GET, POST, …
path Path string, no query. Example: /api/menuitem/經典原味鍋/.
COOKIES Dict of cookie names → strings. sessionid is one key. Parsed from the Cookie header.
headers / META The raw headers. You dump dict(request.headers). Cookie here is one string, not a dict.
body Raw bytes. Empty on a typical GET.
GET / POST Query-string / form fields. Not the JSON body — that is body.

Stamped later (inside get_response)

PocketWho fills it
session SessionMiddleware. Dict-like, on the server, found by sessionid.
user AuthenticationMiddleware. User or AnonymousUser.
resolver_match The menu walk. Missing on a 404.

Docs split these as attributes set by middleware vs the attributes that arrive with the HTTP message.
