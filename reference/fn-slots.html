Function slots

Three extra forms on a def line. Examples from the Python tutorial.

FormHoldsDocs example
self the instance, first argument x.f() ≡ MyClass.f(x)
*args a tuple of leftover positionals concat("earth", "mars", "venus")
**kwargs a dict of leftover keywords cheeseshop(..., shopkeeper="…")

concat

def concat(*args, sep="/"):
    return sep.join(args)

concat("earth", "mars", "venus")
# args = ("earth", "mars", "venus")  sep = "/"
# returns "earth/mars/venus"

cheeseshop

def cheeseshop(kind, *arguments, **keywords):
    ...

# kind        → "Limburger"
# *arguments  → the two positional strings
# **keywords  → shopkeeper, client, sketch

*name before **name. The names args / kwargs are convention.
