Fields P1.2 needs

WantAttributeNotes
pattern route The matching path() string, including include prefixes. On this project a hit of /api/menuitem/經典原味鍋/ gives api/menuitem/<str:slug>/.
url_name url_name May be None if the pattern was unnamed. Namespaces live on view_name / namespaces.
kwargs kwargs Union of captured path converters and extra kwargs from the URLconf. JSON-encode values (ints are fine; UUID is not — default=str if needed).
view func A callable. Do not dump it. See naming below.

Naming func

func = match.func
view_class = getattr(func, "view_class", None)
if view_class is not None:
    view = view_class.__module__ + "." + view_class.__qualname__
else:
    view = func.__module__ + "." + func.__qualname__

Then dump four keys, not the match: 

print(json.dumps({
    "route": match.route,
    "url_name": match.url_name,
    "view": view,
    "kwargs": match.kwargs,
}, ensure_ascii=False))

view_class is what View.as_view() hangs on the wrapper. Django Debug Toolbar's get_name_from_obj does the same. Prefer this over DRF's extra func.cls.
