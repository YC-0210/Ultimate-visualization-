Names bind

Two names can point at one function object. Assignment on the class changes which function the next lookup finds.

function object vs method object

LookupTypePacked instanceCall
MyClass.f / Template.render function object none MyClass.f(x)
x.f / t.render method object x already in x.f()

Docs: “x.f is not the same thing as MyClass.f — it is a method object, not a function object.” Method objects. The wrap stores the class function.

Docs examples

CodeWhat happenedSource
f = fib Second name, same function. f(100) runs fib. Defining Functions
xf = x.f Store a method object; call later with xf(). Method objects
MyClass.f vs x.f Class function vs method object (instance already packed in). same page: “not the same thing”
modname.the_answer = 42 Writable attribute assignment. Namespaces

The wrap

original_render = Template.render   # like f = fib
Template.render = probed_render     # writable class attribute

Store the class function, not t.render. Restore in finally, same as Serializer.is_valid.
