Which object does what

Four names, four jobs — not four labels for one thing.

model · queryset · instance · serializer

One short analogy for the new idea: the recipe on the kitchen wall is not a dish; searching the stock is not a dish; the waiter who reads the ticket is not the stock. Django’s docs call these Type: a Python class — django.db.models.Model subclass, here menuitem. Django’s docs: “A model is the single, definitive source of information about your data… Generally, each model maps to a single database table.” Models , Type: a QuerySet — here menuitem.objects.all(). Django’s docs: “A QuerySet represents a collection of objects from your database.” The Manager objects “is used to retrieve the instances from the database.” Retrieving objects , Type: one Python object — an instance of the model class, here menuitem(pk=…). Django’s making-queries page: the Manager retrieves “the instances from the database.” One row, not the class, not the queryset. Managers , and Type: a DRF serializer — Serializer, here cartitemSerializer. DRF’s docs: serializers convert “querysets and model instances” to native Python types for JSON, and also deserialize — “parsed data to be converted back into complex types, after first validating the incoming data.” Serializers .
