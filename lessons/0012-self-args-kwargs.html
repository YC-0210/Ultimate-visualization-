self, *args, **kwargs

You can already write a named parameter. You do not yet know Python’s three extra forms on a def line.

Where this fits Python, not Django. Your wrap uses these names. Today they get their own examples, from method objects and arbitrary argument lists. See where this sits on the map →

The problem

A def line can list names like voltage. Three other marks exist: self, a star, and two stars. Each catches a different kind of leftover.

Already have

A named parameter

You write the name. The caller fills it.

def parrot(voltage):

Missing

Three extra forms

Instance, leftover positionals, leftover keywords.

self · *args · **kwargs

One short analogy for the new idea: empty pockets on a tray, filled when the diner arrives — not values you write in the workshop. Python’s docs then name the three pockets below. From here on, those names.

1 · self

Docs example: 

class MyClass:
    def f(self):
        return 'hello world'

x = MyClass()
x.f()

The call looks like it has no argument. Python still passes one. Click the two equivalent calls.

Python’s docs: “the instance object is passed as the first argument of the function.” x.f() is “exactly equivalent to” MyClass.f(x). The name Type: the instance, passed as the first argument. “Often, the first argument of a method is called self. This is nothing more than a convention: the name self has absolutely no special meaning to Python.” Method objects is only a convention.

2 · *args

Docs example. Extra positional arguments become a tuple. 

def concat(*args, sep="/"):
    return sep.join(args)

Python’s docs: those extra positionals “will be wrapped up in a Type: tuple — here named args. The star is the catch-all. The name after it is yours. People often write *args. Arbitrary argument lists .” sep is named, so it is not inside that tuple.

3 · **kwargs

Docs example. Named leftovers the function did not list become a dict. Combined with a star: 

def cheeseshop(kind, *arguments, **keywords):
    ...

Call from the docs: 

cheeseshop("Limburger",
           "It's very runny, sir.",
           "It's really very, VERY runny, sir.",
           shopkeeper="Michael Palin",
           client="John Cleese",
           sketch="Cheese Shop Sketch")

Python’s docs: Type: a dict. The usual name is **kwargs. “**name … receives a dictionary containing all keyword arguments except for those corresponding to a formal parameter.” Combined with *name, which “receives a tuple containing the positional arguments beyond the formal parameter list.” Keyword arguments is that dict. *name must be written before **name.
