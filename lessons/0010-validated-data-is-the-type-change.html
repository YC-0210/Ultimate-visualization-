After get_response, this dict is gone. The serializer instance lives inside the view, during is_valid. Same timing as SQL: copy it while the inner call runs, not after it returns. The request never grows a validated_data attribute.

Same wrap, no Django hook

You already wrap execute around get_response. is_valid also runs inside that call. Django gives you execute_wrapper for SQL. DRF does not give you an is_valid wrapper. You replace Type: a method on rest_framework.serializers.Serializer. DRF’s docs: .is_valid() “Deserializes and validates incoming data.” It returns True or False. Access validated_data only after it returns True — the docs say you must call it first, and a failed call leaves no validated dict. DRF validation on the class, call the original, copy, return whatever the original returned. Then put the original back.

json.dumps will fail

Same trap as match.func: a model instance is a live Python object. Copy JSON-safe pieces, and keep the type next to the value — that type is the whole point of this hop.

from rest_framework.serializers import Serializer

def encode(value):
    # JSON-safe primitives keep their Python type name and value.
    if value is None or isinstance(value, (str, int, float, bool)):
        return {"type": type(value).__name__, "value": value}
    # A list: encode each item the same way.
    if isinstance(value, (list, tuple)):
        return {"type": "list", "value": [encode(item) for item in value]}
    # A dict: encode each value. Keys become strings.
    if isinstance(value, dict):
        return {
            "type": "dict",
            "value": {str(key): encode(item) for key, item in value.items()},
        }
    # Django model instance: has pk and _meta. Do not dump the live object.
    if hasattr(value, "pk") and hasattr(value, "_meta"):
        return {
            "type": type(value).__name__ + " instance",
            "value": "pk=" + str(value.pk),
        }
    # Anything else: type name + a short string. Avoid crashing dumps.
    return {"type": type(value).__name__, "value": str(value)[:200]}


# Empty list. Each successful is_valid appends one record.
validations = []
# Keep the real method so we can call it and put it back.
original_is_valid = Serializer.is_valid

def probed_is_valid(self, *args, **kwargs):
    # Run the real method. Skip this and validation never happens.
    result = original_is_valid(self, *args, **kwargs)
    # Only a True result has validated_data. False would raise if you read it.
    if result:
        validations.append({
            "serializer": type(self).__module__ + "." + type(self).__qualname__,
            "data": encode(dict(self.validated_data)),
        })
    # Hand the bool (or raised error) back unchanged.
    return result

Serializer.is_valid = probed_is_valid
try:
    with connection.execute_wrapper(capture_sql):
        response = self.get_response(request)
finally:
    # Always restore. Leaving the wrap on nests a new wrap every request.
    Serializer.is_valid = original_is_valid

captured["validated_data"] = validations
