The func= trap

The rule, in one line: if the wrapper carries view_class, the view string is that class’s module + name; if not (a function view like /login/), it is the function’s module + name.

Shape of the code

After get_response. Skip if there is no match (a 404). view is a string. The other three fields are already JSON-safe. Copy this shape; wiring it into middleware.py is still yours. 

match = getattr(request, "resolver_match", None)
if match is not None:
    func = match.func
    view_class = getattr(func, "view_class", None)
    if view_class is not None:
        view = view_class.__module__ + "." + view_class.__qualname__
    else:
        view = func.__module__ + "." + func.__qualname__
    print(json.dumps({
        "route": match.route,
        "url_name": match.url_name,
        "view": view,
        "kwargs": match.kwargs,
    }, ensure_ascii=False))
